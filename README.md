this mod will add new historical civs into unciv.


Finished (in order of being finished first to last): Norway, Mali, Western Rome, Wales, Switzerland, Aragon, Kushan, Pirate Republic, Guarani, Tibet, Funan, Lithuania, Saxony, The Sea People, Bulgaria, Scotland, Burma (formerly Toungoo), Kongo, Akkad, Croatia, Xiongnu, Rashidun, Jerusalem, Seljuk, Brittany, Kanem-Bornu, Bosnia, Kievan Rus, Wallachia, Afghanistan, Khazaria, Georgia, Tonga, Great Moravia, Ryukyu, Dai Viet, Sicily, the Arameans, Ainu Mosir, Dali, the Amazigh, Cimmeria, Finland, Liguria, Sogdia, Antartica, Greenland, Zabulistan, Mzansi, Imerina

Removed Civs: Holy Romans, Frisia, Khwarazm, Mapuche, Australia, Colchis, Baktria, The Vandals, Danzig, Mogadishu, Monaco, the Seljuks
